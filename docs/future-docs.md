About future documentations:

Future Documentation Overview:

Home.md: Includes Welcome, Requirements, Features, How to Use, and Where to Go Next sections.

dev/: Contains multiple Markdown files detailing the developer API, including managers and their helpers.

dev-api.md: Explains how the QoL scripts work globally, with links to the specific API documentation.  
make-your-first-script.md: Step-by-step tutorial for creating your first script.  
event-api.md: Documentation for the Events Manager and its helper.  
config-api.md: Details for the Config Manager and helper.  
hook-api.md: Explains the Hooking Manager and helper.  
keybind-api.md: Covers the Keybind Manager and helper.  
command-api.md: Documentation for the Command Manager and helper.  
java-interoperability.md: Explains how GraalJS and Java interact, how to extend a Java class via the MQS API, and related topics.  
utils.md: Describes the MQS utilities.

user/: Contains documentation intended for end users.  
user-guide.md: Explains installation, usage, Java arguments, and script loading.  
ui.md: Details the UI, including the scripts list, configurations, keybinds, and settings.
